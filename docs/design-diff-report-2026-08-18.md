## 整体共性问题

1. **状态栏未在 Web 端渲染**
   - 设计稿：每个页面顶部均包含 `data-name="status-bar"`，左侧时间 `9:41`，右侧 signal/wifi/battery 图标（14px）。
   - 当前实现：`<StatusBar />` 组件仅在原生平台配置系统栏并 `return null`，H5/浏览器预览时没有任何 DOM 渲染。
   - 涉及页面：全部 10 个页面。

2. **底部导航顺序不一致 / 部分页面缺失**
   - 设计稿：Tab 顺序统一为 `首页 / 记录 / 发现 / 我的`，当前页高亮。
   - 当前实现：`BottomNav` 组件顺序为 `首页 / 发现 / 记录 / 我的`；`Me`、`Today`、`AddFood`、`Search`、`CameraResult` 等页面未渲染底部导航。

3. **热量数字颜色不统一**
   - 设计稿：食物/结果卡片中的热量统一使用 `#34C759`（主题绿）。
   - 当前实现：Records、Today、AddFood、Search、CameraResult 等食物卡片热量使用 `#E8590C`（橙色）。

4. **食物/结果卡片视觉不统一**
   - 设计稿：48px~56px 彩色渐变图标底图、名称 15px/600、副文案 12px/#9CA3AF、右侧加号圆圈。
   - 当前实现：40px 统一 `#E8F5EC` 绿底图标、名称 14px、副文案多为 `category · unit`、右侧多为文字“+ 添加到xx”。

5. **渐变色值不一致**
   - 设计稿常用：`linear-gradient(135deg, #34C759 0%, #22A85A 100%)`。
   - 当前实现常用：`linear-gradient(135deg, #34C759 0%, #1FA355 100%)`。

6. **页面容器宽度**
   - 设计稿：固定 `width: 375px`。
   - 当前实现：`width: 100%` + `minHeight: 100dvh`，大屏下元素会被拉伸。

7. **分段控件 / 筛选器形式不同**
   - 设计稿：白色 pill chips（高 30px，圆角 15px），含“全部”。
   - 当前实现：`<Seg>` 组件为灰色底、圆角 12px，不含“全部”。

## 逐页差异

### FoodCalorie-Home

#### 1. [布局/缺失] 状态栏未在 DOM 中渲染

- 设计稿：包含 data-name="status-bar"，左侧时间 9:41，右侧 signal/wifi/battery 图标（img/svg，14px）
- 当前实现：使用 <StatusBar /> 组件，仅在原生平台配置系统栏，return null，不渲染任何 DOM 元素
- 影响：H5/浏览器预览时顶部缺少设计稿中的状态栏视觉
- 建议：如需还原设计稿，可增加一个伪状态栏组件，在 Web 端渲染 9:41 与图标；或接受原生差异并在文档中说明

#### 2. [布局/文案] 顶部导航结构不一致

- 设计稿：左侧 "今日"（16px/600），中间标题 "食刻"（18px/700），右侧设置图标（20px img）
- 当前实现：左侧为问候语 + 日期（11px/#9CA3AF）与标题 "食刻"（22px/800），右侧设置图标放在 36x36 白色圆角按钮内（fa-gear）
- 影响：首页头部信息层级、字号、布局均不同
- 建议：按设计稿调整为左 "今日"、中标题、右裸图标；或更新设计稿

#### 3. [布局/样式/文案] 拍照识别卡整体差异

- 设计稿：垂直居中卡片，背景 linear-gradient(129deg,#34C759 0%,#22A85A 100%)，圆角 24px，padding 28px，阴影 0 14px 32px rgba(52,199,89,.35)；包含 76x76 图标容器、标题 "拍照识别食物"（20px/700）、副标题 "一键识别热量与营养"（14px）、底部 279x52 CTA 按钮 "拍照识别"（#34C759 文字）
- 当前实现：水平卡片，背景 linear-gradient(135deg,#34C759 0%,#1FA355 100%)，圆角 20px，padding 18px 20px，无大阴影；图标 52x52，标题 "拍照识别"（17px/800），副标题 "拍一拍，自动识别食物与热量"（11px），右侧 chevron-right 图标，无 CTA 按钮
- 影响：首页核心入口视觉与交互形式差异显著
- 建议：改为垂直大卡片 + 底部圆角 CTA 按钮；统一渐变色为 #34C759->#22A85A

#### 4. [缺失] 缺少 "今日记录" 列表模块

- 设计稿：包含 history-section，标题 "今日记录" + "查看全部"，3 个 food-card（图片 56x56、名称 15px/600、时间 12px/#9CA3AF、热量 16px/700/#34C759、蛋白 11px）
- 当前实现：完全缺失该模块
- 影响：用户无法在首页查看最近记录
- 建议：新增今日记录列表组件，数据可取自 /api/v1/foodcalorie/records 最近几条

#### 5. [多余] 出现设计稿没有的 "今日摄入" 统计卡

- 设计稿：无此模块
- 当前实现：包含 Ring 进度环（110px）、今日目标、可摄入/超出、达标天数等真实数据展示
- 影响：页面信息结构改变
- 建议：若需还原设计稿应移除该卡片并放入 Today 页；若这是产品需求变更则更新设计稿

#### 6. [多余] 出现设计稿没有的 "快捷入口" 宫格

- 设计稿：无此模块
- 当前实现：4 列宫格（记录/发现/我的/拍照），44x44 绿底图标 + 11px 标签
- 影响：页面信息结构改变
- 建议：同上，确认是否为需求变更

#### 7. [布局/文案] 底部导航顺序与图标排列不同

- 设计稿：图标在上、标签在下，顺序 首页 / 记录 / 发现 / 我的
- 当前实现：图标在上、标签在下，顺序 首页 / 发现 / 记录 / 我的；未激活图标色 #C0C4CC，标签 10px
- 影响：Tab 顺序与信息架构不一致
- 建议：统一为设计稿顺序（首页/记录/发现/我的）

#### 8. [样式] 页面容器宽度

- 设计稿：固定 width: 375px
- 当前实现：width: 100%，适配各种屏幕
- 影响：大屏下卡片被拉伸
- 建议：如需严格还原可限制最大宽度 375px 并居中

### P0（必须立即修复）
1. **状态栏 Web 端缺失**：全部页面 H5 预览顶部空白，影响设计还原度。

   - `CameraResult` 当前为多候选 + 单按钮，设计稿为单结果 + 双按钮（重新拍照/确认添加）。

   - 需产品确认最终流程后统一修改。
