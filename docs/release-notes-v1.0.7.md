# 食刻 v1.0.7

发布日期：2026-09-07

## 修复

- Android 正式版提升为 `versionName 1.0.7`、`versionCode 8`，解决旧产物被误装时提示版本较低的问题。
- 页面不再绘制设计稿中的 `9:41`、信号、Wi-Fi 和电池图形，状态信息交由真实系统栏展示。
- APK 构建前强制清理经过路径校验的输出目录，避免旧页面和旧图标资源混入新安装包。
- 月历测试不再硬编码特定月份与 31 天，避免跨月后错误失败。
- 更新受影响的 npm 依赖，前后端安全审计恢复为零已知漏洞。

## 发布安全

- 版本提升脚本拒绝同版本与降版本，并在写入前校验 Web/Android 版本一致。
- CI 在发布前核对 tag、应用 ID、版本信息与 APK 签名。
- 正式 APK 文件名包含 `versionName` 和 `versionCode`，同时发布 SHA-256 校验文件。
- 清理仓库工作区内的历史 debug APK，正式安装包仅以 GitHub Release 为准。

## 安装说明

从 v1.0.6 正式版可直接覆盖升级。如果设备安装的是历史 debug 签名包，Android 会因签名不同拒绝覆盖；确认数据已同步后卸载旧包，再安装 v1.0.7 正式版。
